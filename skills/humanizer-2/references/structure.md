# 他怎么组织信息（重组用）

## 核心：一个问题一个单元

他的文档是一串读者会依次追问的问题。每个问题是一个 ❓ callout，下面直接是答案。大标题只是把几个问题归成一组。

AI 稿常见的毛病和他的做法对比：

| AI 稿 | 他的做法 |
|---|---|
| 按"概念/定义""机制""意义""挑战""展望"这类抽象维度分章，同一件事被拆到三处 | 按读者的追问顺序排，一件事在一个问题里讲完 |
| "X 是什么"和"X 如何工作"各一个二级标题 | 合并成一个 ❓，或者放在同一个大标题下相邻的两个 ❓ |
| 二级标题七八个，每个下面两三句 | 大标题 2 到 4 个，每个下面 2 到 5 个 ❓ |
| 每节末尾一段小结，文末再来一个总结 | 结论写在每个问题的第一行，文末没有总结 |
| 对比信息分散在各节 | 拼成一个对比题："传统的自由基清除剂 vs 我们能自身的氧化还原酶 vs 他们做的自由基清除剂"；或者"区别1/2/3""观点1/2/3"排开 |

## 大标题的顺序

调研/科普类（基准样本「PD-1/VEGF双抗的历史」）：

1. 前言：一句事实 + 这篇要回答的 1 到 3 个问题（编号）
2. 历史背景：名字由来、谁发现、时间线
3. 科学背景：是什么、怎么工作、机制分步
4. 临床事实 / 现实情况：数据、适用范围、风险
5. （需要时）跟我们有什么关系 / 我们怎么看

尽调备忘、给团队看的决策文档（结论必须在最前）：

1. 开头一个 ❓：要不要做、怎么做，下面一句话结论加一两行理由
2. 人和方法：对方是谁、技术是什么
3. 技术/业务拆解：按他们自己的分线（Aim 1/2/3、产品线）排
4. 追问：会上问了什么、哪里站不住
5. 跟我们的关系：给多少、换什么、风险、下一步

注意这类文档和调研/科普正相反，不要把结论挪到最后。判断标准：文档的目的是"让读者学懂一个主题"就用调研顺序，是"让团队做一个决定"就用这个顺序。

其他见过的顺序：

- 从下往上："最底层概念 / 中层：Alternative和伦理 / 顶层：数据和实验结果"（Renewal Bio）
- 按时间讲故事：完整故事线 → 背景科学 → 总结 → 更多科学 → 最后怎么解决的（利托那韦）
- 对外/媒体用：关键问题和回答 → 30 秒版本 → 关键事实 → 横向对比 → 立场 → 补充事实（Right to Try）

周报里每家公司一个 H1，内部大致是：

1. 公司开头 callout：一句话定位，或 Deck / Round / Minimum Check / Minutes
2. 值得提的人 / 融资八卦（"开始之前先说一些有意思的事情"）
3. 他们是做什么的
4. 背景知识（从最基础的讲起："讲复杂机制前，先说神经元和突触都是啥"）
5. 一串追问：为什么、怎么做、证据是什么、为什么难
6. 疑问 / 对方说法哪里站不住
7. 跟我们的关系：为什么找到我们、我们怎么参与、给多少

## 合并规则

1. 两个标题回答的是同一个读者问题 → 合并成一个 ❓。
2. 两个问题读者一定会连着问 → 写进同一个 ❓ 的标题："什么叫热水，多热算热水，为啥我喝热水确实胃舒服?"；"IP是属于UCLA的，那么假如公司被收购了，IP怎么办，利润怎么算"。
3. 一个问题的追问 → 不另开标题，在答案里用一行普通问句接着答（"不会有免疫反应吗？"）。
4. 相关但独立的两个问题 → 同一大标题下相邻的两个 ❓（"FDA一视同仁吗"和"FDA双标吗"）。
5. 定义、术语解释 → 不单独成节，挂在第一次用到它的问题里，用括号或斜体"注："。
6. 原文的"总结/结论/启示/展望"节 → 拆开，把真有信息的句子挪到对应问题的第一行或末尾"所以……"，剩下的删。
7. 原文的"背景"如果只是复述后文 → 删；如果有独立信息 → 放进"历史背景"或"背景知识"。

## ❓ 问题怎么写

- 用读者自己会问的话，口语："VEGF管什么用""PD-1/VEGF双抗是不是一定比单抗好""为什么一个卵母细胞会成熟失败？颗粒细胞在里面的作用是什么？"
- 不写成名词短语式标题（"VEGF的生物学功能概述"）。
- 偶尔可以是一句断言当标题（"PD-1被阻断，同时也会导致自身的免疫性疾病"），后面紧接着用一句话修正或限定（"但多数疾病比较mild，致死率较低"）。

## 问题内部

```
❓ 问题

**一句话答案（加粗）**

1. 要点（一到两个分句）
   a. 子要点
2. 要点
3. 要点

所以……（需要时）

[图]

---
```

机制类问题按步骤编号（"1. PD-1 结合上 PD-L1  2. ITSM 上的酪氨酸被磷酸化……6. 最后T细胞的激活信号被抹除，T细胞关机"），一步一行。

## 改前改后的结构对照（示意）

AI 稿：
```
## 一、PD-1 的定义与发现
## 二、PD-1 的分子结构
## 三、PD-1 信号通路机制
## 四、PD-1 抑制剂的临床意义
## 五、VEGF 的生理功能
## 六、VEGF 在肿瘤微环境中的作用
## 七、双抗的协同机制
## 八、安全性考量
## 九、总结与展望
```

改后：
```
## 前言（一句事实 + 两个问题）
## 历史背景
   ❓ PD-1的含义（并入原一、二）
   ❓ PD-1的历史
## 科学背景
   ❓ PD-1如何工作（原三、四的机制部分）
   ❓ PD-1与PD-L1的结合机制是什么
   ❓ VEGF管什么用（原五、六合并）
## 临床事实
   ❓ PD-1/VEGF双抗是不是一定比单抗好（原七）
   ❓ PD-1被阻断，同时也会导致自身的免疫性疾病（原八）
（原九删除，其中有信息的句子挪进上面对应问题）
```
